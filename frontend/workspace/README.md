# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/87c43e0e-d027-4a4b-a690-37b7a57bcc36

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Configure LLM and image provider credentials in the Django admin console.
3. Run the app:
   `npm run dev`
